## Featured projects

### 🛒 [KLTN-POS](https://github.com/haphu2512-java/KLTN-POS) · Graduation thesis

POS and inventory management for small retail stores, with demand forecasting.

- **Backend:** Java 21, Spring Boot 3, Spring Data JPA, Spring Security with JWT, WebSocket (STOMP) for real-time stock updates, a nightly forecasting job.
- **Clients:** Electron + React desktop app with thermal receipt printing, and an Expo mobile app that works as a wireless barcode scanner.
- **Forecasting:** exponential smoothing and moving average, safety stock and reorder point, checked against a separate Python implementation.
- **Ops:** MySQL 8 and the backend run with Docker Compose; GitHub Actions runs backend tests plus frontend lint and build.

### 🏋️ [gym-management](https://github.com/haphu2512-java/gym-management)

Web app for a gym: members, sales, staff shifts, cash handover and payroll.

- React 19 + Vite + Zustand on the front, Supabase (PostgreSQL, Auth, RPC functions) on the back.
- Access is enforced in the database with Row Level Security; the schema lives in versioned SQL migrations.
- CI runs lint, unit tests and SQL tests against a real Postgres; deployed on Vercel.

### 💬 [ZaloForEdu](https://github.com/haphu2512-java/ZaloForEdu)

Messaging platform for classrooms: class, group and 1-1 chat, file sharing, voice and video calls.

- Node.js + Express + MongoDB backend with a controller / service / model structure and Swagger docs.
- Socket.io for real-time messaging, typing and read receipts; WebRTC for calls.
- React web client and React Native mobile client; JWT authentication with role-based access.

### 📸 [SnapNow](https://github.com/giasinguyen/snapnow-social-media-app) · Team project

Social media platform for sharing photos and stories, built by a team of three for the Mobile Application Development course.

- React Native + Expo + TypeScript mobile app, Express.js backend, React + Vite admin dashboard, all on Firebase (Auth, Firestore, Storage).
- My part, about 100 commits on the mobile app: dark mode across the app, chat themes and group creation, search with hashtags and debounced input, saved posts, story drafts and archive, change and reset password.
- Worked through feature branches and pull requests reviewed by the team.

### 💰 [Asset-Management](https://github.com/haphu2512-java/Asset-Management)

Personal finance mobile app built with React Native, Expo and TypeScript on Supabase.

- Tracks net worth, assets, income and spending, and savings goals; stock and crypto values refresh from market prices.
- Quick entry from text or a receipt photo, with Gemini handling the parsing and spending advice.
- Android builds are produced by an EAS workflow on GitHub Actions.

### 🧩 [software-architecture](https://github.com/haphu2512-java/software-architecture)

Coursework labs on distributed systems: API gateway, microservices for booking and payment flows, RabbitMQ messaging, Redis, and Docker Compose setups.
